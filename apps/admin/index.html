How it works

  1. Create the customer who will own the table (section 1).
  2. Provision a table for that customer (section 2). Copy the table id and the broker login shown there: they appear only once.
  3. Register the table on the broker with the command shown, then check that the table says Online.
  4. Give the customer the pairing QR code. Only that customer can use it.
